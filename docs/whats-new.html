Changelog

What's new

Recent releases have taken WebVigil beyond Windows to macOS and Linux, then tightened what it says and does: Amazon product pages that no longer raise false alarms, a Settings screen that shows the real sign-in choice and an uninstall that removes the browser profiles it used to leave behind.

v1.1.0

Settings shows the real sign-in choice

  • When setup turned on start at sign-in, Settings still showed it unticked, since it read WebVigil's own stored choice. Settings now reads the sign-in entry itself on Windows, macOS and Linux, so it shows what will actually happen
  • Uninstalling with the option to delete your websites, history and settings left the window's browser profile behind. It is now removed with the rest; every uninstall also schedules setup's own browser profile for removal once setup has closed
  • The setup progress bar is weighted by how long each step really takes, measured over twelve installs and an uninstall
v1.0.1

Amazon product pages stop raising false alarms

  • An Amazon product page reshuffles itself on every load, so watching one as text reported a change on nearly every check while the product itself had not moved
  • Enter an Amazon product address in Add or Edit and WebVigil fills in structured fields for the parts that matter: the title, author, formats and prices, rating, review count, description, cover and product details. The sales rank, which moves by the hour, is left out; every field stays visible and editable
  • A site you already watch keeps its current reading until you open it and save it. Saving asks to start a new baseline, as any change to what is compared does
  • If Amazon serves its robot-check page in place of the product, the check reports a failure rather than a change
  • A Windows build no longer fails its formatting check on Go files last committed from a Mac
v1.0.0

WebVigil on macOS and Linux

  • Each release carries one download per platform: a setup program for Windows, a disk image for Macs with Apple Silicon and a Flatpak for Linux
  • Everything that watches pages works the same on every platform, the update check included; it offers the download for the platform you are on
  • The alarm plays on all three, the built-in chime and your own WAV file alike. Start at sign-in works on all three too
  • There is no tray on macOS or Linux, so WebVigil watches while its window is open; closing the window quits
  • On Windows, closing the window now asks whether to minimise to the tray or quit. If you were editing a site, the settings or an import, it says so and offers Go back first
  • Settings, the Guide and the appearance choice name the system you are on rather than always saying Windows
v0.1.0

The first release

  • WebVigil checks the web pages you choose, tells you when their meaningful content changes and says plainly why a check failed. Everything it records stays on your computer
  • Each site is read one of four ways: its visible text, chosen CSS selectors, named fields or the raw response. Noise can be set aside; Preview extraction shows what will be compared before you save
  • The first successful check becomes the baseline. A later check that differs records the change, shows it as a line diff and raises your alarm: a chime or your own WAV file, a Windows notification naming the site or both. A change stays amber until you acknowledge it
  • A failed check is never shown as an old page. It is named (DNS, a refused or timed-out connection, TLS, the HTTP status and more) and makes no sound; one warning appears once a site has failed as many times in a row as its threshold
  • Polite by design: each site has its own interval, five minutes at the shortest. At most four checks run at once; one host is never asked twice within ten seconds; repeated failures back off up to a day
  • Site definitions export to a JSON file and import from one, with a preview first. Nothing is written until you confirm
  • WebVigil lives in the tray and can start when you sign in to Windows. The appearance is light, dark or following Windows
  • The Help menu holds a Guide to every control, About, the full licence and Check for Updates. The daily update check carries no identifier and nothing about your sites
  • A setup program installs WebVigil for your account alone, with no administrator rights. Uninstall keeps your websites and history unless you ask for them to be deleted
